## 二、它能做什么

按「20 年实战复盘分析师」的四步框架组织：

1. **大盘环境** — 三大指数快照、市场宽度、涨停跌停、AI 大盘解读、指数相对强弱走势图
2. **板块轮动** — 热门板块 / 主力资金、主线 vs 轮动判定、主线 × 持仓映射
3. **个股诊断** — K线 + 多空信号 + 艾略特波浪、五维技术评分、短/中/长三周期研判、AI 情景推演
4. **风险情景** — 组合结构、相关性、再平衡建议、大事提醒

## 三、核心原则

- **不编造数据**：所有数字来自真实 OHLCV；取不到就显示「数据缺失」
- **不预测点位**：只做已发生形态的客观描述与情景推演
- **每条结论附数据依据**：指标值、日期、幅度都写在结论旁边
- **末尾必有免责声明**：技术分析有滞后性与失效风险，历史不代表未来

## 四、数据来源

| 用途 | 来源 | 方式 |
| --- | --- | --- |
| 内嵌默认行情 | 公开日K快照（26 只常见标的 + 3 大指数，各 320 根） | 打包进 `index.html`，离线可用，标记 `builtin` 不写 localStorage |
| 联网刷新 | 腾讯 `web.ifzq.gtimg.cn`（`ACAO:*` 可直连）→ 新浪（JSONP）→ 东方财富 | 浏览器直连，自动回退 + 逐源诊断 |
| 全市场搜索 | 腾讯 `smartbox.gtimg.cn`（返回 JS 变量赋值，script 标签直载，天然绕过 CORS） | 输入即搜 |
| 涨跌家数、涨停跌停 | 东方财富 | 需点「↻ 刷新行情」 |
| 你的持仓、成本、笔记、提醒 | — | 浏览器 localStorage，**永不上传** |

> 公司网络可能拦截外网或限制跨域。拉不到数据时：
> ① 在「⑨ 数据后台」换数据源顺序 / 配 CORS 代理；
> ② 或从 Excel / 通达信 / 同花顺复制日K，直接粘贴到「个股诊断」的文本框（逗号、Tab、空格分隔均支持，日期支持 `2026-09-10` / `2026/9/10` / `20260910`）。

## 五、目录结构

```
ashare-review/
├── index.html        # 单文件应用（含全部行情与逻辑，587 KB）
├── echarts.min.js    # ECharts 5.5.1（必须与 index.html 同目录）
├── README.md
├── CHANGELOG.md
├── LICENSE
├── .gitignore
└── _src/             # 模块化源码 + 构建脚本（改代码看这里）
    ├── shell.html    # 页面骨架与样式
    ├── data.js       # 内嵌真实行情与快照
    ├── engine0.js    # 全局状态（须最先加载）
    ├── engine1.js    # 指标计算（MA/MACD/RSI/KDJ/BOLL/ATR/背离/形态）
    ├── engine2.js    # 大盘 / 板块 / 持仓渲染
    ├── engine3.js    # 事件绑定与联网
    ├── engine4.js    # AI 研判（规则推理）
    ├── engine5.js    # K线绘制、批量解析、报告富文本、对比图、笔记
    ├── engine6.js    # AI 深度研判与报告装配
    ├── engine7.js    # 图表可读性（延迟初始化 / 大盘走势 / 雷达 / 评分）
    ├── engine8.js    # K线设置 + 艾略特波浪
    ├── engine9.js    # 多源拉取 + API 后台 + 日志 + 体检
    ├── engine10.js   # 大事提醒 + 持仓盈亏 + 快捷搜索 + 关于
    ├── engine11.js   # 智能添加（索引检索 + smartbox 联网） + 拉取 v2 + 批量解析
    ├── engine12.js   # 后台六模块 + 主题偏好 + 自动化 + 数据字典 + 首次引导
    ├── engine13.js   # 大盘增强：趋势线 / 波浪 / 单指数K线 / 相关性 / 多周期共振
    ├── build.py      # 合并 _src → index.html
    └── verify*.js    # Node 沙箱验证脚本（4=v1 回归 / 5=v2 / 6=2.0 新功能）
```
