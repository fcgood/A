## v2.0.0 — 2026-09-12

**大盘走势工作台：界面重排 + 引导链修复**

- 大盘走势图从「一行挤到底的工具条」重做为**三段式工作台**：头部（动态标题栏）→ 控制台（5 个分组卡片）→ 图形区（图 + 说明 + 状态条 + 快捷键提示）
- 头部实时显示**当前标的 / 图型 / 周期 / 区间 / 数据截至日**，并把已开启的叠加项渲染成标签；右侧固定「↺ 重置 / ⛶ 全屏 / ⤓ 导出PNG」
- 控制台按**图型 · 标的 · 区间 · 画线叠加 · 指标叠加**分五组，不再是 8 组挤在一行；窄屏自动换行，不再出现孤立按钮
- 不适用于当前图型的控件改为**变暗禁用**而非隐藏 —— 切换图型时布局零跳动（此前每次切换「指数 / 周期 / 灵敏度」都会整排闪动重排）
- 原生小复选框换成**开关型 chip**（带勾选方块与选中描边），字号从 11.5px 提到 12.5px，暗色下可读性明显改善
- 图型按钮文案收敛为「三指数 · 归一化 / 三指数 · 涨跌% / 单指数 · K线 / 单指数 · 收盘线」，一眼看清单指 / 三指
- **图下状态条**：把趋势线位置、浪型阶段、均线上下位置浓缩成 chips，不用读长段落
- **图下动态说明**：随图型 / 叠加项实时改写，替代固定的一整段文字
- 新增 **⛶ 全屏查看**（Esc 退出，图表自动 resize）、**↺ 一键重置视图**
- 新增**快捷键**（仅大盘页、输入框内不触发）：`1/2/3` 切上证·深成·创业板，`[` `]` 切区间，`Esc` 退出全屏
- 指数 KPI 卡**可点击**，直接切换下方图表标的（多指数模式下自动切到单指数 K 线）
- **修复引导链缺陷**：`init()` 在 engine10 顶层同步执行，而 engine11~13 的顶层 `var`（`LS_KEYS` / `PREF` / `SRC_LABEL` …）要到脚本求值完才赋值 —— 原实现里 `renderStoragePanel` 读 `LS_KEYS.forEach` 抛错，被外层一个大 `try` 吞掉后，**「大事提醒 / 关于 / 持仓 / 指数图」等后续步骤全部不再执行**。现改为「分步 try + 延后一个事件循环」，单步失败不再拖垮整条引导链
- 新增 `verify8.js`：**120 项**工作台专项验证（结构 / 状态推导 / DOM 同步 / 快捷键 / 全屏 / 渲染结构 / 持久化），并带真实 `classList` 的伪 DOM 以便断言选中态

**大盘行情重做：趋势线 + 艾略特波浪**

- 走势图从「只有归一化折线」扩为 **4 种图型**：三指数归一化 / 三指数涨跌% / **单指数 K线** / **单指数收盘线**
- 单指数模式可切**上证·深成·创业板**与**日线 / 周线**，叠加项可自由勾选：趋势线、趋势通道、艾略特波浪、均线、成交量、面积填充
- **自动趋势线**：ZigZag 找摆动点 → 最近两个递增低点拟合上升线、递减高点拟合下降线 → 线性外推到今日，给出斜率、线位、**突破 / 贴近 / 远离**判定
- **水平关键位**：摆动点价格聚类（±1.2%，出现 ≥2 次），图下以「关键位条」展示支撑 / 压力及**距现价百分比**
- **艾略特波浪**：在指数 K 线上标注 1-2-3-4-5 与 A-B-C 修正段 + 斐波回撤位；新增**浪型阶段进度条**，直观显示当前处于第几浪
- **波浪灵敏度自适应**：指数波动远小于个股（实测上证日线需 2%~3.5%、深成需 4%~6%），默认「自动」逐个尝试阈值直到识别出五浪，也可手动锁定 2%/3%/4%/5%
- **成交量副图**（红涨绿跌 + 量 MA5），主图 / 量图双 grid，Y 轴按可见窗口收紧（实测蜡烛占绘图区 **75%**）
- 指数 KPI 卡加**迷你走势 sparkline** 与**距 MA20 偏离**
- 新增 **指数相关性矩阵**（近 N 日收益率相关系数，看是否齐涨齐跌）与 **日 / 周 / 月多周期共振**（三周期票型 + 共振结论）
- 图型 / 指数 / 周期 / 叠加项**偏好自动记忆**（localStorage），下次打开保持

**加标的：一句话就够**
- 顶部「⚡ 加标的」框 + 个股诊断 / 持仓管理页输入框，统一智能联想
- 任意一种输入都能搜：**6 位代码**（600519）、**拼音首字母**（gmt → 贵州茅台）、**汉字**（茅台 / 半导体）、**简称**
- 内置 **992 条**真实名称索引；本地没搜到会**自动联网检索全市场**（结果标注「网」）
- ↑↓ 选择、回车即加入，并自动补齐 K 线；支持一次粘一整段（一行一个 / 逗号分隔均可）

**拉取：从「总是失败」到说清卡在哪**
- 重写拉取层：腾讯 `web.ifzq.gtimg.cn` 优先（响应头 `ACAO:*`，浏览器可直连），新浪 JSONP 兜底，东财最后
- 逐源记录耗时与错误，失败时给出**可读诊断**（哪个源、什么错、多少毫秒）+ 三步排查建议
- 批量拉取带进度；失败自动铺好粘贴模板（支持 Excel / 通达信 / 同花顺复制）

**后台管理：从「只有 API」扩为六模块**
1. 数据源与 API（开关 / 优先级 / 地址模板 / 代理 / 日志）
2. **数据缓存**（每只标的根数、区间、来源、占用，可单删 / 批量清）
3. **存储用量**（localStorage 明细与占用率条）
4. **偏好设置**（主题 / 字号 / 默认周期视野 / 启动行为）
5. **自动化任务**（定时刷新行情与提醒扫描）
6. **诊断与自检**（一键看清数据够不够、哪儿坏了）

**隐私默认：可安全公开发布**
- 内置持仓清零 —— **应用不内置、不上传任何人的持仓**
- 内置 26 只常见标的与三大指数的公开行情快照（离线演示用，标记 `builtin` 不写 localStorage）
- 说明页移除全部持仓相关表述，并加入隐私声明

**新增能力**
- 深色 / 浅色 / 护眼三主题切换
- 指标数据字典（13 个指标：是什么、怎么用、有什么坑）
- 标的分组（持仓 / 自选 / 观察 / 已清）
- 首次使用引导 + 一键载入示例标的

**保留并增强的 v1 能力**：四步复盘框架、图表可读性（延迟初始化修复 0×0 图表）、K线显示设置与艾略特波浪、大事提醒、持仓成本盈亏、Ctrl+K 快捷搜索、复盘笔记、走势对比。
