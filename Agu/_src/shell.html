使用说明

1. 数据来源：内置 26 只常见标的与三大指数的真实日K公开快照（—）与板块资金快照，离线可用。
　⚠️ 本工具不内置、不上传任何人的持仓——持仓列表由你自己添加，只保存在这台电脑的浏览器里，清缓存会丢失，请定期导出备份。
2. 刷新：点顶部「↻ 刷新行情」由浏览器直连腾讯/东方财富刷新指数与涨跌家数（需可访问外网）。
3. 加标的（一句话就够）：顶部「⚡ 加标的」框，或个股诊断 / 持仓管理页的输入框 —— 随便敲一种都行：
　① 代码：600519、159558、000001
　② 拼音首字母：gmt → 贵州茅台、zxtx → 中兴通讯
　③ 汉字：茅台、半导体、券商
　输完自动出候选，↑↓ 选择、回车即加入，并自动补齐 K 线。本地索引涵盖近 1000 只常见标的，
　本地没搜到会自动联网检索全市场（标注「网」的结果）。
　也可以一次粘一整段（一行一个、逗号分隔都行）：「600519 贵州茅台 / 300750 / 宁德时代 / gmt」。
　若联网失败，可直接粘贴日K（Excel / 通达信 / 同花顺复制，逗号、Tab、空格分隔均可）。
4. K线图（个股）：可切日/周线、主图 MA/BOLL、副图 MACD/KDJ/RSI；6 套显示预设（裸K / 均线排列 / 布林带 / 趋势通道 / 波浪 / 全开）、MA5~MA250 自由勾选、实心·空心·美国线、对数坐标；视野 20/40/60/90/180/全部；高度「紧凑/标准/大图」+「全屏」；「自适应量程」开关让蜡烛始终撑满主图。
4b. 大盘走势工作台：顶部标题栏实时显示当前标的 / 图型 / 周期 / 区间 / 数据截至日与已开启的叠加项，右侧为重置 / 全屏 / 导出PNG。
控制台按图型 · 标的 · 区间 · 画线叠加 · 指标叠加分五组，不适用当前图型的控件会变暗而非消失（切换图型时布局不跳动）：四种图型——三指数归一化 / 三指数涨跌% / 单指数K线 / 单指数收盘线；单指数模式可切上证·深成·创业板与日/周线，叠加趋势线、趋势通道、艾略特波浪、均线、成交量、面积填充；波浪灵敏度默认「自动」，会为每个指数挑一个能识别五浪的阈值。
图下依次为状态条（趋势线位置 / 浪型阶段 / 均线位置）、关键位条（支撑压力距现价%）、趋势线解读、浪型进度条与区间统计（涨跌 / 高低 / 最大回撤 / 年化波动）。
快捷键（仅本页生效、输入框内不触发）：1 / 2 / 3 切上证·深成·创业板，[ / ] 切区间，Esc 退出全屏。点击上方任一指数卡片可直接切换图表标的。偏好自动记忆，下次打开保持。
5. 复盘报告：支持富文本 / 纯文本切换与小/中/大三档字号（自动记忆）；顶部带目录跳转；每个标的含「五维共振拆解 + 情景推演 + 操作纪律 + 历史相似形态统计」。
6. 走势对比：勾选 2～6 只标的做归一化对比，看区间内的相对强弱、最大回撤、年化波动与收益/回撤比。
7. 复盘笔记：按标的记录你的判断与触发计划，存本机浏览器，支持关键词过滤。
8. 信号含义：红=多头技术形态，绿=空头技术形态，均为客观形态识别结果，不是买卖指令。
9. 备份：「备份/恢复」可导出/导入全部本地数据 JSON，防清缓存丢失。
